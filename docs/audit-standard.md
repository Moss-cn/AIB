# A-Level AI 视频画质审核定义标准 v1.0

**版本**：1.0（2025）
**状态**：草案（配套实现：`alevel/` 工具与浏览器版 `index.html`）
**上位文档**：《AI视频画质等级体系 A1–A10 完整构建方案》v1.0（草案）

---

## 1. 目的与范围

本文件定义 **A-Level 认证**（A1–A10）的审核标准：审核对象、等级定义、评分标尺、判定规则、
审核流程、报告规范与防伪验证。适用于对 AI 生成视频（文生视频/图生视频/视频编辑产物）进行技术画质等级审核。

范围不包括：内容合规性（色情/暴力等）、版权、道德伦理审核——A-Level 仅度量**技术画质**。

## 2. 术语与定义

| 术语 | 定义 |
|------|------|
| 审核单元 | 一次等级判定的最小单位：单段视频片段（≥2 秒），或长视频按规则切分后的片段 |
| 画质等级 | A1–A10 的离散等级，A10 为最高技术画质（见 §4） |
| 维度 | 画质的可度量方面：A–E 核心五项 + F–H 进阶三项（见 §5） |
| 自动指标 | 由程序从视频帧序列计算出的量化值（见 §7） |
| 置信度 | 自动指标与其真实世界对应物之间的映射可靠程度：high / medium / low |
| 标定 | 将自动指标原始值映射到 1–5 分的过程（用人工标注语料回归拟合） |
| 审核结论 | 一次审核单元判定的最终等级与依据 |

## 3. 审核对象与审核单元

### 3.1 审核对象
- 输入：单段 AI 生成视频文件（MP4/WebM 等浏览器或 ffmpeg 可解码格式）。
- 不接受：拼接多段不同来源视频（需先切分为独立审核单元）、加有水印/台标的成片（干扰自动指标）。

### 3.2 审核单元规则
- 单段 ≤ 30 秒：整段为一个审核单元。
- 单段 > 30 秒：按 30 秒窗口切分，或由委托方指定关注区间（如仅人物特写段）。
- 每审核单元独立判定、独立签发等级。

### 3.3 采样规范（自动指标输入）
| 参数 | 值 | 说明 |
|------|-----|------|
| 采样帧率 | 10 fps | 时间维度的统一采样率 |
| 最大帧数 | 120（浏览器 60） | 指标计算窗口上限 |
| 分析尺寸 | 宽 ≤ 256 px（浏览器 128） | 统一分析分辨率，等比缩放 |
| 帧类型 | 灰度（亮度通道） | 当前自动指标基于亮度域 |

## 4. 等级体系定义（A1–A10）

| 等级 | 公众定位 | 判定语义 |
|------|----------|----------|
| A1 | 草稿预览 | 明显畸形/闪烁/物理错误，仅限内部预览 |
| A2 | 基础可用 | 可看但有明显瑕疵 |
| A3 | 标清可用 | 基本可用，细节与稳定性一般 |
| A4 | 高清可用 | 普通观众可接受，偶见小问题 |
| A5 | 高清良好 | 技术稳定，无明显缺陷 |
| A6 | 高清优秀 | 接近真实拍摄，极少伪影 |
| A7 | 影院级 | 与真实拍摄难以区分 |
| A8 | 超高清级 | 细节丰富，物理合理（需 F 维度） |
| A9 | 超高清优秀 | 极高保真，长期一致（需 F/G） |
| A10 | 世界模拟级 | 完全可信，通过严格校验（需 F/G/H） |

## 5. 维度定义与评分标尺（1–5）

### 5.1 通用评分语义
| 分值 | 通用语义 |
|------|----------|
| 5 | 与真实世界（或指定虚拟世界）无差异 |
| 4 | 需放大或慢放才可察觉的细微瑕疵 |
| 3 | 一般观众可察觉，但不影响内容理解 |
| 2 | 明显瑕疵，影响观感或部分影响理解 |
| 1 | 严重缺陷，无法正常观看/理解 |

### 5.2 核心五项（A–E，必测，决定 A1–A7）

**A 有效空间分辨率** —— 画面中真实、清晰、可用的细节量
- 5：细节丰富且均为真实结构；4：极少数区域轻微涂抹；3：细节中度损失/部分区域糊化；2：大面积糊化或锐化过度产生振铃；1：几乎无有效细节。

**B 时间稳定性** —— 连续播放的稳定程度（闪烁/抽帧/抖动/身份漂移）
- 5：运动流畅无闪烁；4：极轻微抖动仅慢放可见；3：可见闪烁或轻微抽帧；2：频繁闪烁/明显抽帧/抖动；1：持续大幅闪烁或身份漂移。

**C 结构完整性** —— 手、脸、文字等关键结构是否正常
- 5：全部结构正常；4：个别结构轻微变形（如手指略粗）；3：结构明显异常但可辨认（如五根半手指）；2：结构错误难以辨认（六指、五官错位）；1：严重畸形（面部崩坏、文字乱码、关键结构缺失）。

**D 物理一致性** —— 光影、反射、碰撞、重力等是否符合物理规律
- 5：光影/反射/运动完全合理；4：极个别光影矛盾仅慢放可见；3：可见光影矛盾或悬浮/穿透等小问题；2：多处明显物理错误；1：物理规律系统性失效（光影漂移、物体无碰撞反应）。

**E 纹理自然度** —— 表面质感是否自然（无塑料感/伪影/色块）
- 5：质感真实，含自然噪点与细节；4：极轻微“AI 塑料感”；3：明显塑料感或压缩伪影；2：严重伪影/色块/纹理涂抹；1：纹理完全失真。

### 5.3 进阶三项（F–H，A8–A10 门槛及模型能力校验）

- **F 3D 几何一致性**：视角变化下几何关系是否正确（5=透视/遮挡完全正确；1=几何漂移系统性失效）。
- **G 长期时空记忆**：长视频中身份/物体/场景是否保持一致（5=全程一致；1=身份或物体持续漂移）。
- **H 因果与交互合理性**：接触、推动、遮挡等交互是否符合因果（5=完全合理；1=交互系统性错误）。

## 6. 等级判定规则

### 6.1 综合得分

核心五项每项 1–5 分，综合得分（2–10 分制）：

    Composite = (0.20·A + 0.30·B + 0.20·C + 0.15·D + 0.15·E) × 2

B（时间稳定性）权重最高，因其是 AI 视频最普遍、最影响观感的失效模式。

### 6.2 等级阈值

| 等级 | 综合分 | 核心项最低要求 | 进阶项要求 |
|------|--------|---------------|-----------|
| A1 | ≥2.0 | — | — |
| A2 | ≥3.0 | — | — |
| A3 | ≥4.0 | — | — |
| A4 | ≥5.0 | C≥3 | — |
| A5 | ≥6.0 | B≥3 | — |
| A6 | ≥7.0 | B≥4, C≥4 | — |
| A7 | ≥8.0 | A–E 全部 ≥4 | — |
| A8 | ≥8.5 | A–E 全部 ≥4.5 | F≥4 |
| A9 | ≥9.0 | A–E 全部 ≥4.5 | F≥4.5, G≥4 |
| A10 | ≥9.5 | A–E 全部 ≥5 | F≥4.5, G≥4.5, H≥4.5 |

> ⚠️ 已知缺陷（标准修订中）：A5 仅要求 B≥3（C 要求不累积）。修订方案：改为要求累积（每一级继承更低级全部核心项要求）。

### 6.3 一票否决

| 触发条件 | 等级上限 | 可操作化判定 |
|----------|---------|-------------|
| C 严重畸形（六指/面部崩坏/文字乱码） | A2 | C 得分 ≤1，或人工/探针标记 c_severe |
| B 持续大幅闪烁或身份漂移 | A3 | B 得分 ≤1，或人工/探针标记 b_severe |

否决为**上限约束**：判定等级 = min(阈值判定等级, 否决上限)。

## 7. 自动指标定义（审核的客观依据）

所有自动指标输入为按 §3.3 采样的灰度帧序列。指标原始值经**标定函数**（分段线性）映射到 1–5 分。

| 维度 | 指标 | 数学/算法定义 | 置信度 |
|------|------|--------------|--------|
| A | hf_ratio | 2D FFT 后半径 > 0.25·Rmax 环形带能量 / 总能量（均值） | medium |
| A | res_retention | 帧降采样 2× 再双线性恢复后与原帧的 NCC（归一化互相关） | medium |
| B | flicker | 减去时间均值后，逐像素时间轴 FFT 中 >0.35·Nyquist 能量占比 | medium |
| B | flow_smooth | 块匹配光流（16px 块/搜索±8/步长8）运动场的均值绝对散度 | medium |
| C | morphing | 块匹配光流（搜索±4）像素级对齐后，边缘加权不可解释残差 | low–medium |
| C | face_rate / face_jitter | Haar 级联人脸检出率与边框中心抖动（cv2 可用时） | medium |
| D | light_consistency | 强梯度（top15%）方向圆均值合成向量长度 R（0..1） | low |
| D | luminance_flux | 全局亮度序列的均值绝对差分 | low |
| E | blocking | 8px 块边界梯度与块内梯度之比偏离 1 的程度 | low |

### 7.1 置信度规则
- **high**：指标与其真实世界对应物高度相关（需标定验证 ρ>0.8）。
- **medium**：可用作初筛（标定验证 0.6<ρ≤0.8）。
- **low**：仅作参考/诊断，不单独支撑等级结论。
- 当前实现中：A/B 为 medium，C 为 low–medium（无人场景按中性 3.0 处理），D/E 为 low。

### 7.2 标定要求
- 正式发布前，须在 ≥500 段带人工标注的视频上完成指标标定（分段线性/逻辑回归拟合 1–5 分映射）。
- 标定验收：自动分与人工分 Spearman ρ>0.6（及格）/ >0.8（优秀）。
- 标定参数固化于 `spec.CALIBRATION`，随标准版本管理。

## 8. 审核流程

### 8.1 主路径：全自动审核（默认）

1. **输入校验**：解码、时长、采样规范检查。
2. **自动指标**：计算 A–E 五项指标并映射为 1–5 分。
3. **等级判定**：按 §6 计算综合得分、核查阈值与否决项，输出等级。
4. **报告**：生成 JSON + Markdown 报告（§9）。

### 8.2 复核路径：自动 + 人工复核（认证级审核推荐）

- 触发条件（任一）：目标等级 ≥A7；存在 low 置信度指标；自动分落在等级边界 ±0.3 内。
- 复核要求：≥2 名评估员按 §5.2 标尺独立评分；差异 >1 分需讨论复评；取中位数。
- 最终等级 = min(自动判定, 人工复核)（保守原则）。

### 8.3 申诉
- 委托方可就等级结论申请复测：使用相同审核单元与版本号重跑；如指标输入或标准版本未变，结论应可复现。

## 9. 报告规范

报告（JSON）必须包含：

| 字段 | 内容 |
|------|------|
| schema_version | 标准版本号 |
| video | 文件信息（分辨率/fps/时长/编码） |
| scores | 各维度得分、来源（auto/manual）、指标原始值 |
| grade | 等级、综合得分、分制、否决信息、逐级要求核查 |
| metric_details | 各指标原始值与置信度 |
| model_level | （可选）模型能力分级 L1–L3 |

Markdown 报告面向公众展示：等级徽章、维度表、判定过程、免责声明。

## 10. 认证标识与防伪验证

- 认证标识：**A-Level 盾牌徽章 + 等级数字 + 验证哈希**。
- 验证方式：取审核单元视频的 SHA-256 哈希 + 签发时间，查询认证系统；哈希不匹配即无效。
- 等级证书有效期：建议绑定标准版本号（如 A7 / 标准 v1.0），标准修订后旧证书标注“已过版本”。

## 11. 质量保证

1. **版本化**：标准、等级表、标定参数均版本化管理；修订须发布变更说明。
2. **数据透明**：定期发布各模型 A 等级对比报告与失败案例（DxOMark 模式）。
3. **防作弊**：定期轮换未公开测试用例，防止生成厂商针对用例过拟合。
4. **审计**：认证实验室须保留审核单元、采样参数、指标原始值与版本号，可追溯复核。
