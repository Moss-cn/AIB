## 1. 体系设计评审（发现的缺陷与修补建议）

### 1.1 发现一：综合得分公式与附录 C 矛盾（必须修）

- 方案 3.2 定义：综合得分 = (Σwᵢ·sᵢ) × 2，映射到 **2–10 分制**，A7 阈值 8.0。
- 附录 A 示例 (4,4,5,4,4) 按公式应为 **8.4 → A7**。
- 附录 C 却写“综合得分 4.1 → A7”——4.1 是 **1–5 分制**的写法，与正文矛盾；且 4.1 按 3.3 阈值只能评 A3。
- **修补**：统一为 2–10 分制（本工具默认），或明确 1–5 分制并重排阈值。本工具两种分制均实现（`--scale 1-5`），并保证同一组分数跨分制评级一致（有测试覆盖）。

### 1.2 发现二：等级表核心项要求不单调（逻辑缺陷）

| 等级 | 综合分 | 核心项要求 |
|------|--------|-----------|
| A4 | ≥5.0 | C≥3 |
| A5 | ≥6.0 | **B≥3**（C 要求消失！） |
| A6 | ≥7.0 | B≥4, C≥4 |

后果：C=2（结构明显畸形）的视频综合分 8.8 时仍可评 **A5 高清良好**——比 A4 还高一级，违背常识。
本工具忠实实现了方案原文（测试 `test_grade_boundaries` 专门固化该行为），但**强烈建议修订为“要求累积”**：
每个等级继承所有更低等级的 core 要求（A5 = min 6.0 且 C≥3 且 B≥3；A6 = 且 C≥4…）。

### 1.3 发现三：“等效技术画质”隐喻有风险

- A7 “等效 4K”、A10 “等效 8K+” 的表述，会让公众重新用分辨率思维理解 A 等级，恰恰违背方案 1.1 的初衷（高分辨率 ≠ 高画质）。
- A8+ 的“等效 5K/8K”没有客观锚点——F/G/H 维度测的是几何/记忆/因果，与分辨率无关。
- **修补**：等级旁只保留公众定位（草稿预览/影院级/世界模拟级），删去或弱化“等效 xxK”；对外话术统一为“像不像真的/可信度”。

### 1.4 其他待明确项

1. **一票否决的“严重”无操作定义**：本工具用“维度得分==1 或显式 flag”操作化（`c_severe`/`b_severe`），方案应写明判定细则（如六指=手部关键点≥21 异常、文字乱码=OCR 错误率>30%）。
2. **自动分与人工分的融合规则未定义**：“加权平均或人工修正”二选一会导致同一视频在不同实验室评级不同。建议固定为：自动分定上限 + 人工分修正（本工具当前为人工分直接覆盖对应维度）。
3. **身份漂移归类**：方案 3.4 把身份漂移（本质是 G 维度）列在 B 的否决项下，建议明确“短时闪烁→B 否决；长时身份漂移→G 维度扣分”，避免双重计分。

## 2. 逐维度技术可行性矩阵

对照方案 4.1 的自动评估指标清单，评估各维度的自动化成熟度（截至 2025 年公开工具水平）：

| 维度 | 方案建议指标 | 现有工具成熟度 | 自动化可行度 | 主要障碍 |
|------|-------------|---------------|-------------|---------|
| A 有效空间分辨率 | FFT 高频能量、盲超分一致性 | FFT 现成；盲超分（BSRGAN 类）需参考 | 🟡 中 | “有效分辨率”无公认定义；高频能量可被噪声/锐化欺骗；需与人工感知标定 |
| B 时间稳定性 | 光流一致性、关键点追踪漂移 | RAFT/GMFlow 成熟开源；MediaPipe 追踪现成 | 🟢 高 | 快速运动时光流失效（本工具 demo 中 testsrc2 B 分失真）；长视频需分窗 |
| C 结构完整性 | 手部/人脸/OCR | MediaPipe Hands、InsightFace、PaddleOCR 均成熟 | 🟢 高（检测）/ 🟡 中（判定） | “畸形”是异常检测，需自训分类器或阈值标定；T06 文字需标准用例 |
| D 物理一致性 | 光源方向、反射匹配 | 论文级方法（光照估计 SfSNet 等），无产品化工具 | 🔴 低 | 无公开基准；阴影/反射一致性难以端到端量化 |
| E 纹理自然度 | AI 伪影检测、LPIPS | NIQE/BRISQUE 无参考；LPIPS 需参考 | 🔴 低 | “塑料感”高度主观，自动指标只能做弱代理（本工具已标注 low confidence） |
| F 3D 几何一致性 | 深度估计一致性、多视角重建 | Depth Anything V2 现成；COLMAP 对生成视频效果不稳 | 🟡 中低 | 生成视频几何漂移导致多视角重建失败率高；属研究级 |
| G 长期时空记忆 | 身份余弦相似度漂移 | ArcFace/CLIP 现成 | 🟢 中高 | 仅人脸场景指标清晰；通用物体身份需自建检测+跟踪管线 |
| H 因果与交互合理性 | 穿透检测、事件因果链 | 无现成工具 | 🔴 低 | 需实例分割+深度+场景图组合，研究级；建议先人工评估 |

**结论**：方案 4.1 的指标清单“方向正确但难度不均”——B/C/G 可以落地；A 需要代理指标；D/E/F/H 短期只能靠人工评分或研究性探针。任何对外认证必须采用 **自动初筛 + 人工复核** 的混合流程（方案 4.3 已正确指出）。

## 3. 数据与标注可行性

### 3.1 基准数据集

- **规模**：方案第八章“1000+ 段 AI 视频”合理。需覆盖 T01–T08 核心用例 + T09–T12 进阶用例，建议每用例 80–150 段，来源：可灵、Runway、Pika、Sora、Veo、开源模型（CogVideoX、HunyuanVideo、LTX-Video 等）多模型抽样，避免单一模型偏差。
- **正负样本平衡**：必须刻意采集“有六指/闪烁/物理错误”的失败样本——真实生成流中失败样本占比可能不足 20%，而标定一票否决阈值恰恰最需要它们。
- **版权与合规**：AI 生成视频标注集无版权风险，但需注意提示词元数据留存（可追溯模型+种子）。

### 3.2 人工评估协议（方案 4.2 评审）

| 项目 | 方案设计 | 可行性 | 建议 |
|------|---------|--------|------|
| 评估员数量 | ≥3 名独立打分 | ✅ | 4–5 名更好，可支持轮换与离群剔除 |
| 一致性校验 | 差异>1 分讨论复评 | ✅ | 增加 ICC（组内相关系数）>0.7 的准入线 |
| 最终得分 | 中位数或均值 | ✅ | 中位数抗离群，推荐 |
| 培训 | 示例视频统一标准 | ✅ | 需建 50–100 段的“金标准锚定集”持续校准 |

**成本估算**：每段视频 5 维度评分 + 缺陷标注约 10–20 分钟，3 人独立 + 10% 复评 → 每段约 0.75–1.2 人时；1000 段 ≈ **4–6 人月**（含培训与质控）。若含 T07 长视频（>30s）成本上浮 50%。

### 3.3 自动指标标定（关键工程步骤）

自动指标（如 FFT 高频比、闪烁指数）的 1–5 分映射**必须由人工标注数据回归标定**，否则自动分与人工分不可比。标定流程：
1. 500+ 段带人工分的视频，计算各自动指标原始值；
2. 对每个指标做分段线性/逻辑回归拟合（或直接拟合等级阈值）；
3. 交叉验证：指标-人工分相关性（Spearman ρ>0.6 为及格，>0.8 为优秀）；
4. 把标定参数固化进 `spec.CALIBRATION`（本工具的映射即为待标定占位）。

**本工具现状**：已实现 A/B/E 三个自动指标及标定接口，但参数是占位值（README 已声明），正式使用前必须完成上述标定。

## 4. 配套工具现状（已交付原型）

本仓库 `alevel/` 实现了一个可运行的评估工具：

| 模块 | 内容 | 状态 |
|------|------|------|
| `spec.py` | 权重/阈值/否决/用例/标定参数集中配置 | ✅ 忠实实现方案 3.2/3.3/3.4/5.x |
| `engine.py` | 综合分计算、等级判定、一票否决、模型能力分级 L1–L3 | ✅ 14 项测试覆盖 |
| `metrics/` | A(FFT+分辨率保留)、B(闪烁+光流)、E(块效应) 自动指标；MediaPipe/RAFT/OCR/Depth/ArcFace 探针骨架 | ✅ A/B/E 可用；探针待装依赖 |
| `cli.py` | grade / evaluate / demo / probes 四个子命令 | ✅ 端到端可用 |
| `report.py` | JSON + 中文 Markdown 报告 | ✅ |

**演示验证结果**（合成视频，C/D 为占位 3.0）：static 综合 8.04 → A5；flicker B=2.60 → A4；noise B=1.00 → A3。指标对闪烁/噪声/静止的区分方向正确，证明管线成立。

**能力边界（必须明确）**：
- 自动指标 ≠ 正式评级：标定前仅供初筛/研发演示；
- C/D/F/G/H 的自动测量依赖重型探针（需装 mediapipe/torch 等）或人工评分；
- 快速运动场景下块匹配光流失效（建议接 RAFT 探针改善）；
- 当前未实现批处理/API/可视化界面（路线图内属平台工程，非本原型范围）。

## 6. 风险与开放问题

### 6.1 技术风险
1. **指标-等级相关性未验证**：方案从未证明“综合分 8.0 = 影院级”的主观感知成立。需在发布前做**感知验证实验**（盲评：A 等级 vs 人工感知排序的 Spearman 相关性）。
2. **模型迭代过快**：2025 年主流模型已能生成稳定 10–30s 视频，A1–A3 区间可能快速空心化，等级表需预留修订机制（版本化，如 A-Level 1.1）。
3. **对抗性过拟合**：生成厂商可能针对测试用例调优（如同 benchmark 作弊），需定期轮换未公开用例。

### 6.2 市场风险
1. **标准竞争**：Dover（2024，AIGC 视频质量评估）、FAST-VQA 等学术指标，以及各家平台自研 MOS 体系——A-Level 的差异化在“公众可理解的等级+认证品牌”，而非指标本身。
2. **“等效 4K”话术争议**（见 1.3）可能被竞争对手攻击为换汤不换药。
3. **认证公信力**：没有第三方独立性就没有公信力；初期“自证”容易遭质疑，需要 1–2 家知名第三方实验室背书。

### 6.3 开放问题（建议成立顾问委员会决策）
- “等效分辨率”映射到底保留还是删除？
- A8–A10 是否首发（建议推迟，先发 A1–A7）？
- 自动分/人工分融合权重；评估员准入标准（是否要求影视行业背景）；
- 是否接受厂商付费送测（公信力与商业化的平衡）。

## 7. 分阶段建议与结论

### 建议路线（修订版）

**阶段 0（0–3 个月）· 可行性质检（本工具可复用）**
- 用 `alevel/` 对 50–100 段主流模型视频跑自动指标 + 2 名评估员盲评；
- 检验：自动分与人工分相关性（ρ>0.6 继续，否则砍掉弱指标）；A 等级分布是否合理；
- 输出：指标取舍清单 + 标定参数 v0.1 + 修补后的等级表（解决 §1 三处缺陷）。

**阶段 1（3–6 个月）· MVP 认证（A1–A7）**
- 定稿核心用例集 T01–T08（先不做 T09–T12）；
- 正式发布 A1–A7 等级（A8+ 标“预留”）；自动维度限 B/C/G，D/E 人工必评；
- 邀请 1 家平台内测（建议先从 See Dance 自己的生成链路开始）。

**阶段 2（6–12 个月）· 品牌与生态**
- A-Level 认证标识 + 哈希查询系统 + 首批对比测试报告（DxOMark 模式）；
- 与 2–3 家头部平台谈互认；发布白皮书 v1.0。

**阶段 3（12 个月+）· 进阶维度与国际化**
- F/G/H 研究性探针转正（依赖深度/身份一致性研究的进展）；
- 联盟 + IEEE/ISO 路径（按年计，勿作为短期目标）。

### 总体结论

《A1–A10 体系》的**核心洞察成立**——AI 视频需要一套以“世界模拟可信度”为核心的等级语言，且 B/C/G 三个维度的自动化测量已经成熟。方案的主要问题不在方向而在**执行细节**：三处设计缺陷必须修补；“自动评估全覆盖”的预期必须收敛为“自动初筛 + 人工复核”；“等效分辨率”话术必须淡化。按修订后的 MVP 路线，**12 个月内发布 A1–A7 认证在技术、数据、预算上均可行**；A8–A10 应作为 2–3 年研究路线而非首发承诺。
