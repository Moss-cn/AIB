# A-Level 画质评估 · AI 生成视频等级认证工具

基于《AI视频画质等级体系 A1–A10》草案实现的可运行评估工具 + 可行性报告。

> **A-Level 认证（A1–A10）**：以「世界模拟可信度」为核心的多维画质等级体系，取代传统分辨率（720p/1080p/4K）在 AI 生成视频领域的适用性。A10 为最高技术画质。

## 🚀 开箱即用（零安装）

**浏览器直接使用（推荐）**：打开 [index.html](./index.html) 即可。

- **🎬 自动评测（主功能，全自动）**：上传 AI 生成视频 → 浏览器本地解码抽帧 → Pyodide（WebAssembly 版 Python + NumPy）运行 **A–E 五项全自动指标**，直接给出 A1–A10 等级与报告，**全程无需人工评分**。视频不上传服务器。
  - A 有效分辨率：FFT 高频能量 + 降采样恢复保真度
  - B 时间稳定性：时间域高频闪烁 + 光流光滑度
  - C 结构完整性：运动补偿结构残余（+ cv2 可用时 Haar 人脸检出增强）
  - D 物理一致性：主光照方向一致性 + 亮度时间稳定性
  - E 纹理自然度：块效应强度
- **✍️ 人工评分（标定/复核用）**：A–E 与 F–H 滑块即时出级，供基准标注、阈值标定与人工复核；自动评测结果也可在此人工修正。
- 部署到 GitHub Pages 后可直接通过网址访问，无需安装任何软件。

## 🐍 Python CLI（完整版）

```bash
cd alevel
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt   # 仅 numpy；需系统 ffmpeg
python -m alevel.cli demo --outdir demo          # 全流程演示
python -m alevel.cli evaluate 视频.mp4            # 全自动评测 (A–E 五项)
python -m alevel.cli grade --scores '{"A":4,"B":4,"C":5,"D":4,"E":4}'
```

17 项单元测试全通过；JS 引擎与 Python 引擎 93,750 组评分组合全量比对一致。

## 📐 评分体系（方案 3.2/3.3/3.4）

- 核心五项 A–E 每项 1–5 分；**综合得分 = (A×0.20 + B×0.30 + C×0.20 + D×0.15 + E×0.15) × 2**
- A1–A10 等级阈值见 [spec.py](alevel/alevel/spec.py)；A8+ 需进阶维度 F/G/H
- 一票否决：C 严重畸形 → 上限 A2；B 持续大幅闪烁/身份漂移 → 上限 A3

## ⚠️ 已知方案缺陷（详见可行性报告 §1）

1. 附录 C「综合 4.1 → A7」与正文公式（8.4 → A7）矛盾
2. 等级表核心项要求不单调：A5 仅要求 B≥3，C 要求消失
3. 「等效 4K/8K」话术与「高分辨率≠高画质」初衷矛盾

自动指标当前为占位标定，正式评级需在真实语料上重新标定（可行性报告 §3.3）。
